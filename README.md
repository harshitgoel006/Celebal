# Celebal Summer Internship 2026

This repository contains all assignments completed during the Celebal Summer Internship 2026.

## Assignments

### Assignment 1 - Basic Data Cleaning

#### Objective
Perform data cleaning and preprocessing on the provided e-commerce dataset using Python and Pandas.

#### Tasks Performed
- Loaded dataset using Pandas
- Explored dataset structure
- Checked shape, columns and data types
- Identified missing values
- Handled missing values
- Checked and removed duplicate records
- Filtered products based on rating
- Selected specific columns for analysis
- Created a new calculated column (`total_amount`)
- Exported cleaned dataset

#### Files
- `Basic_Data_Cleaning.ipynb`
- `cleaned_casual_shoes.csv`

#### Tools Used
- Python
- Pandas
- Jupyter Notebook
