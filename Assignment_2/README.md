# SQL Based Data Analysis using MySQL

## Overview

This assignment focuses on performing SQL-based data analysis using MySQL. It covers fundamental SQL concepts such as filtering, aggregation, sorting, grouping, joins, constraints, transactions, and business-oriented queries on an e-commerce sales database.

The objective is to analyze the given dataset and extract meaningful insights by writing efficient SQL queries.

## Tasks Performed

- Created and used the required database
- Created tables with appropriate constraints
- Inserted sample data into all tables
- Verified data using SQL queries
- Retrieved records using SELECT and WHERE
- Performed filtering using multiple conditions
- Applied aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- Used GROUP BY and HAVING clauses
- Sorted records using ORDER BY
- Performed INNER JOIN and LEFT JOIN operations
- Implemented CASE statements
- Executed SQL transactions using START TRANSACTION and COMMIT
- Explained ACID properties and database concepts
