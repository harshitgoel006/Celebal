# Week 5 - Spark Data Cleaning, Transformation and Aggregation using DataFrames

## 📌 Overview

This project demonstrates the fundamentals of Apache Spark using PySpark. It focuses on performing data cleaning, filtering, aggregation, schema modification, and building a complete data processing pipeline using Spark DataFrames.

The implementation was completed as part of the **Celebal Technologies Internship - Week 5 Assignment**.
